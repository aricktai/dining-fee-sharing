# Product Specification

## 功能
- 日期、時間、餐廳、總餐費、小菜總額
- A/S/E/J/P 人員選擇
- 平均分攤
- 個別金額
- 單一付款人
- 多人付款
- 即時差額
- 自動計算誰欠誰
- 目前位置
- OSM 附近餐廳
- Google Maps
- ⭐ 常用地點
- 今日紀錄
- 歷史紀錄
- 歷史登入
- 歷史搜尋
- 歷史單筆刪除

## 個別金額
選擇後「個人主餐」欄位必須為空白，不得自動帶入平均金額。系統顯示每人的「小菜/人」，並自動以「個人主餐 + 小菜/人」算出應付金額。

小菜總額已包含於總餐費；平均分攤仍只以總餐費除以人數。小菜為空白或 0 時視為 0。

Example:
總餐費 NT$500、小菜 NT$60
A 主餐=100, S 主餐=200, E 主餐=空白

顯示：
`應付合計：NT$360 / 總餐費：NT$500 / 尚差：NT$140`

## 多人付款
同樣即時計算付款合計與總餐費差額。

## 結算
Balance = paid - owed
正值為應收，負值為應付。

## 歷史
匿名只能操作今日資料；authenticated 可查看與管理完整歷史。
