# Product Specification

## 功能
- 日期、時間、餐廳、總餐費
- A/S/E/J/P 人員選擇
- 平均分攤
- 個別金額
- 單一付款人
- 多人付款
- 即時差額
- 自動計算誰欠誰
- 目前位置
- OSM 附近餐廳
- Google Maps
- ⭐ 常用地點
- 今日紀錄
- 歷史紀錄
- 歷史登入
- 歷史搜尋
- 歷史單筆刪除

## 個別金額
選擇後欄位必須為空白，不得自動帶入平均金額。

Example:
總餐費 NT$500
A=100, S=200, E=空白

顯示：
`應付合計：NT$300 / 總餐費：NT$500 / 尚差：NT$200`

## 多人付款
同樣即時計算付款合計與總餐費差額。

## 結算
Balance = paid - owed
正值為應收，負值為應付。

## 歷史
匿名只能操作今日資料；authenticated 可查看與管理完整歷史。
